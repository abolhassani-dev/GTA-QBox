# Mars Community 2 | مارس کامیونیتی ۲

سرور رول‌پلی GTA V روی پلتفرم **VMP**، با فریم‌ورک **QBox**.

QBox نسخه‌ی جدید و بهبودیافته‌ی QBCore است. اسکریپت‌هایی که برای QBCore ساخته شده‌اند (از جمله بیشتر اسکریپت‌های ایرانی که با برچسب «QBCore» فروخته می‌شوند) روی QBox هم اجرا می‌شوند.

## ساختار پوشه‌ها

```
GTA-QBox/
├── docs/                 راهنماهای فارسی قدم‌به‌قدم
└── server-data/          همان پوشه‌ای که روی سرور اجرا می‌شود
    ├── server.cfg        تنظیمات اصلی سرور
    ├── secrets.example.cfg   نمونه‌ی فایل رمزها (کپی کنید با نام secrets.cfg)
    └── resources/        اسکریپت‌ها و فریم‌ورک
```

## روش کار

- **دولوپر (Claude):** همه‌ی کدها، تنظیمات، رفع باگ و راهنماها را در همین ریپو می‌نویسد.
- **صاحب سرور:** سرور را اجرا می‌کند، داخل بازی تست می‌کند و خطاها را (متن پنجره‌ی سرور یا اسکرین‌شات) می‌فرستد.
- رمزها و کلیدها **فقط** در `server-data/secrets.cfg` روی خود سرور نوشته می‌شوند و هیچ‌وقت در گیت یا چت قرار نمی‌گیرند.
