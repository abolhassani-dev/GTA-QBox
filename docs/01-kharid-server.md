# راهنمای خرید سرور – Mars Community 2

این راهنما می‌گوید چه سروری بخرید، از فروشنده چه چیزهایی بپرسید و بعد از خرید چه اطلاعاتی برای دولوپر بفرستید.

---

## ۱. چه نوع سروری؟

**سرور مجازی (VPS) ویندوزی در دیتاسنتر داخل ایران**، ترجیحاً تهران.

- **چرا ویندوز؟** سرور VMP و ابزارهایش روی ویندوز ساخته و تست شده‌اند. نصب و مدیریت با ریموت دسکتاپ هم برای شما ساده‌تر است.
- **چرا ایران؟** پینگ بازیکن‌ها پایین است و اگر اینترنت بین‌الملل قطع شود، بازیکن‌های داخل ایران باز هم می‌توانند وصل شوند.

> نکته‌ی فنی: سرور GTA بیشتر به **سرعت هر هسته‌ی CPU** (فرکانس) وابسته است تا تعداد هسته‌ها. یک CPU با ۴ هسته‌ی سریع از ۱۶ هسته‌ی کند بهتر است.

| سیستم‌عامل | Windows Server 2019 | **Windows Server 2022** |

## ۳. سؤال‌هایی که حتماً قبل از خرید از فروشنده بپرسید

این‌ها را کپی کنید و برای پشتیبانی فروشنده بفرستید:

1. **«امکان ارتقای پلن بدون نصب مجدد ویندوز و بدون پاک شدن اطلاعات وجود دارد؟»** باید جواب «بله» باشد. این برای رشد سرور مهم‌ترین سؤال است.
2. **«مدل و فرکانس CPU سرور میزبان چیست؟»** اگر فقط گفتند «۴ هسته»، مدلش را بپرسید.
3. **«پورت 30120 روی TCP و UDP باز است یا خودم می‌توانم بازش کنم؟»**
4. **«محافظت ضد DDoS دارید؟ روی ترافیک UDP بازی هم کار می‌کند؟»** سرورهای بازی زیاد حمله‌ی DDoS می‌خورند.
5. **«ترافیک بین‌الملل محدود است؟ موقع قطعی اینترنت، سرور از داخل ایران در دسترس می‌ماند؟»**
6. **«امکان گرفتن اسنپ‌شات یا بکاپ از کل سرور دارید؟»**
7. **«ترافیک ماهانه محدود است؟ اگر بله، چقدر؟»**
8. **«آپتایم تضمینی و پشتیبانی ۲۴ ساعته دارید؟»**

### ❌ این‌ها را نخرید
- هاست اشتراکی یا «هاست بازی» آماده که دسترسی ریموت دسکتاپ نمی‌دهد
- سرور لینوکسی (فعلاً)
- پلنی که CPU آن «اشتراکی و نامشخص» است و فروشنده مدلش را نمی‌گوید
- سرور خارج از ایران (برای این پروژه)

---

## ۴. بعد از خرید، این‌ها را برای دولوپر بفرستید

✅ **بفرستید:**
- سیستم‌عامل نصب‌شده (مثلاً Windows Server 2022)
- مشخصات نهایی (CPU، RAM، هارد)
- آیا پورت 30120 باز است یا نه
- آیا از روی سرور به GitHub و سایت vmp.ir دسترسی دارید (در مرورگر خود سرور باز کنید و ببینید)

🔒 **نفرستید:** رمز ریموت دسکتاپ، رمز پنل فروشنده و هر رمز دیگری. دولوپر به رمز نیازی ندارد. همه‌ی کارها را خودتان با راهنمای قدم‌به‌قدم انجام می‌دهید.
