# مرحله ۱ – نصب پایه‌ی سرور (روی سرور ترکیه)

این راهنما را قدم‌به‌قدم جلو بروید. هر جا خطا دیدید، **همان‌جا متوقف شوید** و اسکرین‌شات بفرستید.

همه‌ی کارها روی **سرور ترکیه** (از طریق ریموت دسکتاپ) انجام می‌شود.

---

## قدم ۱ – نصب Git
Git برنامه‌ای است که آخرین تغییرات من را روی سرور شما می‌آورد.

1. این آدرس را در مرورگر سرور باز کنید: **https://git-scm.com/download/win**
2. روی **Click here to download** کلیک کنید (نسخه‌ی 64-bit).
3. فایل را اجرا کنید و در همه‌ی صفحه‌ها فقط **Next** بزنید، آخر سر **Install** و **Finish**.

---

## قدم ۲ – دانلود پروژه
1. دکمه‌ی **Start** ویندوز را بزنید، تایپ کنید `PowerShell` و آن را باز کنید.
2. این دو خط را **یکی‌یکی** کپی کنید، داخل PowerShell راست‌کلیک کنید (پیست می‌شود) و Enter بزنید:

```
cd C:\MarsCommunity
```

```
git clone -b claude/loving-hawking-i12niz https://github.com/abolhassani-dev/GTA-QBox
```

3. اگر پنجره‌ای برای ورود به GitHub باز شد، با حساب GitHub خودتان وارد شوید.
4. حالا باید پوشه‌ی `C:\MarsCommunity\GTA-QBox` ساخته شده باشد. ✅

---

## قدم ۳ – نصب دیتابیس (MariaDB)
دیتابیس جایی است که اطلاعات بازیکن‌ها (کاراکتر، پول، ماشین و...) ذخیره می‌شود.

1. آدرس **https://mariadb.org/download/** را باز کنید.
2. گزینه‌ها: **MariaDB Server** ← آخرین نسخه‌ای که کنارش نوشته **LTS** ← سیستم‌عامل **Windows** ← **x86_64** ← پکیج **MSI**. بعد **Download**.
3. فایل را اجرا کنید و Next بزنید تا به صفحه‌ی رمز برسید:
   - تیک **Modify password for database user 'root'** را بزنید و یک رمز قوی بنویسید.
   - ⚠️ **این رمز را یک جای امن یادداشت کنید** (برای من نفرستید). در قدم ۵ لازمش دارید.
4. صفحه‌ی بعد: تیک **Install as service** روشن بماند، پورت **3306** بماند. Next ← Install ← Finish.

---

## قدم ۴ – فایل‌های سرور VMP
فایل‌های سرور VMP از سایت **https://artifact.vmp.ir/** دانلود می‌شوند (در خود سایت vmp.ir توضیحی درباره‌اش نیست).

1. آدرس **https://artifact.vmp.ir/** را باز کنید.
2. روی **بالاترین نسخه‌ی لیست** کلیک کنید (در زمان نوشتن: **100301**). فایل `server-artifact.7z` دانلود می‌شود.
   - اگر بعداً دولوپر گفت، نسخه‌ی Recommended (100201) را امتحان می‌کنیم.
3. فایل دانلودشده را **Extract** کنید داخل این پوشه (اگر نیست، بسازیدش):
   `C:\MarsCommunity\GTA-QBox\artifacts`
   - اگر پسوند فایل `.7z` بود، اول برنامه‌ی **7-Zip** را از https://www.7-zip.org نصب کنید، بعد روی فایل راست‌کلیک ← 7-Zip ← Extract files.
4. بعد از Extract باید فایل **FXServer.exe** (یا اسمی شبیه آن) مستقیم داخل پوشه‌ی `artifacts` باشد.

---

## قدم ۵ – نصب خودکار (QBox و همه‌چیز)
1. در پوشه‌ی `C:\MarsCommunity\GTA-QBox\tools` روی فایل **install.bat** دوبار کلیک کنید.
2. اگر ویندوز پرسید «اجازه می‌دهید تغییر ایجاد کند؟» **Yes** بزنید.
3. چند دقیقه صبر کنید تا دانلودها تمام شود.
4. وقتی پرسید `Type the MariaDB ROOT password`، رمزی که در قدم ۳ گذاشتید را تایپ کنید و Enter بزنید (موقع تایپ چیزی نشان داده نمی‌شود؛ عادی است).
5. آخر کار باید **DONE** سبز ببینید.

این برنامه خودش این کارها را انجام می‌دهد: دانلود QBox و همه‌ی اسکریپت‌های پایه، درست کردن مشکل لایسنس راک‌استار برای VMP، ساخت دیتابیس، ساخت فایل رمزها و باز کردن پورت 30120.

---

## قدم ۶ – روشن کردن سرور
1. در پوشه‌ی `C:\MarsCommunity\GTA-QBox` روی **start.bat** دوبار کلیک کنید.
2. یک پنجره‌ی سیاه باز می‌شود و متن‌هایی در آن می‌آید. این پنجره همان سرور است؛ **نبندیدش**.

---

## اگر خطا دیدید
همه‌ی متن پنجره‌ی سرور خودکار در پوشه‌ی `C:\MarsCommunity\GTA-QBox\logs` ذخیره می‌شود. **جدیدترین فایل** آن پوشه را برای من بفرستید (فایل را بکشید و داخل چت بیندازید). همین کافی است.

---

## بعداً: گرفتن تغییرات جدید از من
هر وقت گفتم «آپدیت کردم»:
1. پنجره‌ی سرور را ببندید.
2. روی **update.bat** دوبار کلیک کنید.
3. دوباره **start.bat** را اجرا کنید.
