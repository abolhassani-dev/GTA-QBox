# سیستم مواد Mars – مرحله ۱ (ماری‌جوانا)

اسکریپت اختصاصی `mars_drugs` – کد از صفر نوشته شده، قفل ندارد و روی VMP کار می‌کند.

## چرخه‌ی کامل

```
خرید بذر ← کاشت ← آب و کود ← رشد (۳۰ دقیقه) ← برداشت گل خیس
        ← خشک کردن (خشک‌کن) ← بسته‌بندی (میز + کیسه‌ی خالی) ← فروش به NPC
```

| مرحله | کجا / چطور |
|---|---|
| **خرید** | فروشگاه باغبانی، ساحل Vespucci (روی نقشه آیکون دارد). بذر ۴ نوع، آب، کود، کیسه‌ی خالی |
| **کاشت** | بذر را از کیف «استفاده» کنید – فقط فضای باز، حداکثر ۶ گیاه |
| **مراقبت** | با Alt (ox_target) روی گیاه: وضعیت / آب دادن / کود دادن |
| **کیفیت** | ۴ سطح: ضعیف، متوسط، بالا، اگزوتیک – میانگین مراقبت در کل دوره‌ی رشد |
| **برداشت** | وقتی رشد ۱۰۰٪ شد – تعداد گل (۴ تا ۱۲) به کیفیت بستگی دارد |
| **خشک کردن** | خشک‌کنِ لابراتوار مخفی (مزرعه‌های Grapeseed) |
| **بسته‌بندی** | میز لابراتوار – هر ۲ گل خشک + ۱ کیسه‌ی خالی = ۱ بسته |
| **فروش** | Alt روی هر عابر پیاده ← «فروش جنس». ۷۰٪ قبول می‌کند؛ اگر رد کند ممکن است به پلیس خبر بدهد |

قیمت فروش = قیمت پایه‌ی نوع × ضریب کیفیت (اگزوتیک ۲.۲ برابر).

## دستورهای تست (فقط ادمین)

| دستور | کار |
|---|---|
| `/drugkit` | ۲ بذر از هر نوع + ۱۰ آب + ۵ کود + ۲۰ کیسه |
| `/druggrow` | گیاه‌های اطراف شما فوراً کامل رشد می‌کنند |
| `/druglab` | تلپورت به لابراتوار |
| `/drugshop` | تلپورت به فروشگاه بذر |

## تنظیمات
همه‌چیز در `server-data/resources/[mars]/mars_drugs/config.lua` است: زمان رشد، قیمت‌ها، شانس فروش، محل لابراتوار و فروشگاه.

## مراحل بعدی
- مرحله ۲: لابراتوار شیشه و کوکائین
- مرحله ۳: کارگرها، اپ گوشی (پلاگ)، اعتیاد و اثر مصرف
